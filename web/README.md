# Interface web Campus Agenda

Application web de l’agenda scolaire (espace enseignant, Carnet, vue élève, administration).

## Développement

```bash
pnpm install
pnpm dev
```

Prévisualisation locale : `pnpm run preview:node` (`http://127.0.0.1:5173`).

Production Infomaniak / SQLite : voir `docs/OPERATIONS.md` et `docs/infomaniak-deploy.md`.
